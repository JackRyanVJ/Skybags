# Skybags E-Commerce Platform

Official modern, minimalist e-commerce web application for **Skybags** ("Move In Style"), tailored for teens, young professionals, and college-going students.

## 🌟 Key Features
- **Branding & Theme**: Skybags Deep Navy & Royal Blue (`#0a1f38` / `#0066cc`) with energetic Yellow (`#facc15` / `#ffd000`) accents.
- **Login Options**:
  - Continue with Google (OAuth simulation)
  - Login with Email & Password
  - Login with Mobile (OTP)
  - 1-Click Student Login (Varad Jadhav - Mumbai University BBA)
  - Skip & Explore as Guest
- **Product Catalog (30 Authentic Products)**:
  - **10 Backpacks (₹1,000 – ₹2,500)**: Dedicated 15.6" & 16" laptop armor sleeves, hydro-shield water resistance, and 25L–35L volume.
  - **10 Suitcases & Sets (₹5,000 – ₹15,000)**: TSA locks, 360° spinner wheels, virgin polycarbonate shells.
  - **10 Duffel Bags (₹3,000 – ₹5,000)**: Inline roller wheels, shoe garages, 45L–64L volume.
- **Indian Checkout**: UPI (GPay, PhonePe, Paytm, QR scan), Credit/Debit Cards, Netbanking, COD, and PIN code auto-fill.
- **Order Cancellation**: Cancel active undelivered orders with instant 100% refund tracking.
- **Store Locator**: Pan-India flagship store directory with interactive map preview.
- **Bag Finder Quiz**: 3-question AI student matcher.

## 🚀 Running Locally
```bash
npm install
npm run dev
```
